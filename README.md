# Atlas Agents sandbox

A throwaway two-page static site, served by GitHub Pages, that exists only so the
[Atlas Agents](https://github.com/Atlas-BM/Atlas-Agents) apply run can be tested against a
real GitHub repository: it audits the site, plans edits, opens a pull request, merges it on
request, and reverts it.

Nothing here is real. Delete this repository whenever you like.
